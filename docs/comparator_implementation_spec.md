## 方法与交付

- NSGA-II-LS：POX拓扑交叉(.9)、六类变异(.2)、非支配排序/拥挤距离/精英保留；每代ceil(N/8)个精英各至多2次局部精评。
- MOEA/D：相同编码及遗传算子，邻域10、交配概率.9、每子代至多替换2个子问题；固定归一化尺度及动态理想点。
- DCAN-adapted：128维、2层、4头条件注意力；工序邻接、机器竞争及工人服务竞争；可学习候选评分，公共标量critic和PPO优化。来源commit caf60d8da721382c79009539a9c8d9ccbc39e734；不宣称原奖励/环境的直接复现。
- Rule-DDQN：7个阶段规则，合法映射去重，mean/max观测池化，256x256线性Q头；Double-Q、gamma1、Huber、replay100000、warmup1024、batch128、每4步更新、每1000梯度步同步目标、clip5。交付为贪心单次。
- 搜索保留解码器的表达范围限制。所有实际候选通过原生环境验证；变异清除旧replay_actions。

- 用户选择远端手动启动。本轮只交付代码和本机小实例/回归证据，不自动连接或启动远端实验。
