# Schema 10：机器承诺与连续服务投影

本版本将候选时间、人工费、停机费和承诺负荷方差从同一条安全服务路径计算。
观测仍为六类节点、十四类关系和九维全局向量，V8 网络结构与物理动作规则继续沿用。

主线集成采用 V2 数据目录和冻结尺度 `(1089.15,353.27,2.2629)`，活动网络入口为 `agent/ppo/network.py`。候选投影与九维特征口径保持本页定义，schema-10 模型重新训练。下文 2026-10-05 的原始桌面分支验收采用当时配置；主线合并验收另记录在本文末尾。

## 服务路径

`environment/resource_projection.py` 提供纯计算的 ResourceProjector。空闲工人从当前
时间/疲劳开始；忙碌工人从实际任务结束时刻及完成后的疲劳开始。初始负荷为当前承诺
负荷，已有活动阶段不会再次增加承诺时长。

每个拆卸工人分支独立保存可用时刻、疲劳和负荷，再枚举安装工人。阶段等待期间恢复
疲劳，执行阶段累加疲劳，工期沿用现有 ceil 时间格。选择完整安装结束最早的路径；
并列按拆卸工人、安装工人索引稳定决策。因此最快拆卸工人可能不是最快完整路径。
source=target 时无需重构；source=A0 时仅安装。时间、费用和方差均取选定路径。

可安全执行但完成超过期限的路径保留有限预计时间和负裕量。没有安全路径时返回 None，
观测以 horizon_tick+1 的有限哨兵表达不可达，并将安全备选数置零。该投影不修改 mask。

## 机器承诺与边语义

候选边分为三种情况：正在加工的实际工序使用历史开始/实际结束；LOCKED 实际工序
只补齐当前重构剩余部分再加工；其他工序先等待机器完成全部现有承诺，然后从释放
后的模块开始估计自己的重构和加工。未来订单不得在释放前开始。

| 特征 | Schema 10 口径 |
|---|---|
| processing_time_norm | 完整加工时长/horizon |
| earliest_start_time_norm | 该候选预计加工开始；实际 PROCESSING 边为历史加工开始 |
| resource_ready_time_norm | 首个必要服务阶段的开始；无重构时为加工开始；活动阶段残余从当前时刻计算 |
| predicted_finish_time_norm | 同一服务路径后接加工的完成时间；实际 PROCESSING 边使用 busy_until |
| horizon_slack_norm | 期限减上述完成时间，再归一化/裁剪 |
| reconfiguration_time_norm | 本候选重构段等待、恢复和服务持续时间；不含此前普通加工占用 |
| fixed_disassembly/installation_cost_norm | 本候选未来阶段固定费，已支付的活动阶段固定费不重复计入 |
| estimated_labor_cost_norm | 选定工人各阶段服务时长×费率；活动阶段仅计未来剩余服务 |
| estimated_downtime_cost_norm | 本候选重构段从承诺开始到结束的完整等待/执行停机费 |
| estimated_worker_load_variance_delta_norm | 同一路径末负荷方差减该候选开始前承诺负荷方差 |

前置机器承诺的投影不计入新候选费用；它的负荷结果作为新候选方差基准。
当前阶段的实际时刻和任务采用真实映射读取，不对 A0 虚构拆卸。
configuration_match 仍表达当前模块是否匹配，匹配缺口仍诊断当前任务，不重复加入
已存在的锁定任务。安全备选数来自服务路径分支，安装备选使用拆卸后疲劳。

候选缓存按状态版本、机器、目标模块、订单释放及实际任务身份区分；分支阶段计算不
复用只按真实环境索引的旧缓存。时间与负荷数据在分支间复制，缓存随统一入口失效。

## 订单时间与运行契约

OrderTimeEstimator 复用相同阶段投影。每条订单链的假设资源独立演化；已有机器承诺
在该分支内仅物化一次，后续工序延续已选路径的工人状态。其他订单的未决定任务不
构成固定全局排程。它提供软预计裕量，不承诺全局最优未来调度。

WAIT 合法性和启发式基线使用的乐观下界函数保持其原口径，实际事件、奖励、mask、
失败结算和外部截断不随投影层修改。stage_wait_time 等既有实际工人候选指标保持定义。

由于特征计算语义改变，观测版本升级为 **10**，时间上下文为
`order_chain_action_context_v2`。runtime manifest、配置快照与 network spec 引用统一常量。
schema 9 及更早模型/快照明确拒绝，迁移开关不能绕过；需要重新训练。
策略头 V8、结果格式 8.0.0 和 failure-v3 奖励协议保持现有版本。
持久化基准、manifest 和冻结目标尺度保留原文件。
