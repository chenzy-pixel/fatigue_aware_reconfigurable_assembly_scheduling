# 主线实验协议

更新：2026-10-17。本文前半部分对应原有PPO主线；新对照套件的交互预算和数据划分在下文单列。执行矩阵见[实验清单](experiment_runlist.md)，远端操作见[对照启动说明](comparator_remote_startup.md)。

## 模型与冻结条件

默认 [配置](../configs/default.json) 为 schema12、log2、HGNN shared-head、excess Flow、OWA(q=.5)，PPO `gamma=1`、`gae_lambda=.95`、dropout=0。Universal 训练 2000 episodes，单目标训练 1000；每次 PPO 更新采集 20 episodes。

尺度取自 [冻结清单](../configs/manifests/workload_excess_q50_20261011.json)：Flow=368.3143、Cost=353.27、Workload=21.03145448655653。实验内冻结尺度；不同目标模式、OWA q、尺度和观测编码属于不同身份，评估模型时使用其保存配置。

全局累计目标输入为 `log2(1+J/s)`。质量坐标为 `q_i=J_i/(s_i+J_i)`，使用配置中的 augmented Tchebycheff 标量化，rho=.05。奖励为 `ΔP-ΔQ-2I_failure`，附加势函数项关闭。

## 数据、验证与选模

训练实例按固定算法种子在线生成；验证与测试使用提交的 V2 固定数据及对应哈希。改变训练种子不改变固定验证/测试协议。

Universal 每 100 episodes 验证：固定分层 50 实例 × 13 偏好 × 3 次采样，共 1950 请求、650 交付。偏好包括三端点、三边中点、等权中心和 `(0.6,0.3,0.1)` 的六个排列。

单目标每 40 episodes 验证，仅使用相应 one-hot 偏好。正式解码使用 sampled、temperature=1。同实例、同偏好的三次请求按成功优先、Q 更低优先、采样序号更小优先取优。

Universal checkpoint 按取优后的最差偏好完成率优先，再比较偏好平衡 Q；单目标按取优后的整体完成率优先。安全且完整的首次验证初始化 best，同分保留原 best。每次训练保存 last，最终测试重载 best；无有效 best 时明确报告。

## 测试与公平比较

Universal 最终测试使用 step=.1 的 66 点 simplex 网格，每实例、偏好三次采样。原始请求、被选交付、完整性、安全性和全部推理预算同时报告；详见 [聚合契约](default_best_of_three.md)。

PPO单因素比较固定实例、训练种子、目标模式、尺度、更新预算、选模、解码与求解预算。raw Flow、variance、不同 q、编码或 lambda 使用 [显式对照](ablation_protocol.md)。跨方法按下文区分交互、优化和交付预算；新默认协议与历史逐采样协议分别解释，不重写历史结果。

结果目录保存有效 config、provenance、checkpoint、训练/验证日志、完整原始评测行和被选行。预检、启动和完成是不同状态；smoke 用于检查集成，不说明训练质量。

## 新对照套件：匹配训练与合理搜索

[comparison_suite_v1](comparator_implementation_spec.md)包含新训练的HGNN-PPO、DCAN适配版、Rule-DDQN，以及NSGA-II-LS、MOEA/D和MO-ALNS v2。物理环境、schema12/log2输入、疲劳、目标与冻结尺度沿用主线；网络、动作映射和搜索机制分别记录。DCAN使用本项目标量奖励和PPO优化，DDQN学习选择合法派工规则；它们均为同环境适配。

- **训练预算**：PPO/DCAN/DDQN各用11/23/37训练种子，从头训练，每次精确350411次实际env.step；每方法3个学习率先以seed11、35041步调参。该步数由旧PPO日志标定，既不等于固定2000 episodes，也不复用旧权重。所有真实步骤含WAIT计费，关闭forced compression；选模档位和总预算截断保留自举。等交互不等于等优化或等计算，必须另报更新次数、样本重用、训练和验证耗时。
- **数据隔离**：500例validation按固定哈希分出21调参、21选模、7确认实例，覆盖七类压力且互斥。调参4偏好；正式训练按20/40/60/80/100%步数档位，用21例×13偏好选best；确认集只用于冻结后的独立比较。它不是原PPO主线50例选模协议的静默替换。
- **交付协议**：PPO/DCAN主表为best_of_3_v1，同时报告greedy诊断；DDQN为greedy_single_v1。每种搜索每偏好单独初始化和付费，一次交付来自本请求按时完成的候选。各方法使用自身选模协议，完整保留原始候选、安全、失败和时限记录。
- **搜索预算**：NSGA-II-LS/MOEA/D先在7例调参集选择16/32/64种群，再在21例×4偏好×3搜索种子上跑600秒曲线，未达平台或机制门槛则完整扩展至1800秒；MO-ALNS在alns_reference独立校准。初始化、早期、充分搜索分列；默认600秒和旧300候选上限都不直接充当已证明充分的正式预算。最长档位仍改善或机制不足，标记充分性未确认。
- **短时限**：另用同实例、偏好的新PPO三次取优实际交付时延给搜索设限。每模型固定候选三元组重复计时三次取中位数，再取三个模型时延的中位数；不增加选优候选。短时限只交付初始解时如实报告，不据此推断充分搜索的整体强弱。

独立确认包括7例×13偏好×3种子，每臂273份交付，11臂共3003份。先在实例—偏好内平均方法自身的训练/搜索重复，再与PPO配对；搜索种子与训练种子不视为同一种重复。报告完成覆盖、共同成功集Q/三目标、含失败损失、13点交付HV、全部付费档案HV和按整个实例bootstrap的区间；确认样本每压力仅一例，区间使用pooled实例bootstrap。整前沿共享档案属于独立实验，费用与全部偏好请求累计成本比较。

远端由用户手动执行预检和`--stage all --remote-run`；本机只保留小实例与回归证据。`all`依次调参、训练、曲线、确认和报告，停在正式manifest。`formal-evaluate`另行运行已冻结臂的test/OOD/stress 66偏好评测，预算未充分或搜索相对初始化最优解的独立改善未确认时拒绝展开。该门槛不要求搜索超过PPO。阶段、命令、身份与恢复细节见[远端说明](comparator_remote_startup.md)；当前实现证据与性能边界见[验证记录](comparator_verification_20261017.md)。

## 独立挑战集

独立冻结的[challenge_v1](challenge_suite_protocol.md)补充100例五类瓶颈测试和20组四档重构倍率配对，共180例。它用于选模、超参数和搜索预算冻结后的评价，不进入主线50例验证或对照套件21/21/7划分。test_hard条件于参考启发式可解；倍率集保留全部档位及unknown，并另报四档共同获证书子集。1.6为训练倍率边界，1.8/2.0为该因子外推，不代表订单/机器/工人规模外推。

当前challenge入口支持冻结PPO与启发式；完整网格每模型为180×66=11880份PPO交付、35640条原始PPO轨迹，启发式180条物理轨迹重评分为11880行。统计以瓶颈实例或配对基础组为单位，三训练种子需各用独立目录及真实权重；默认历史seed11 smoke不代表三模型评价。已物化、已审计和小规模链路完成不等于正式全量评价完成。
