# 当前代码架构

更新：2026-10-24。

## 执行路径

`scripts.experiment_suite`读取冻结实验清单，展开七配置和五种子，经`agent.comparators.learning.train_request`执行episode预算训练，经公共请求评价实现生成前沿和独立请求结果，最后由`analysis.experiment_suite`生成报告。三个PowerShell实验组入口调用相同编排器。

配置只加载当前schema13及factorial-27冻结尺度。`data`负责固定实例、哈希清单和在线训练计划；`environment`维护事件驱动仿真、动作合法性、疲劳安全、图观测和三目标。节点为工序、机器、工人、订单、模块，观测与奖励定义见实验规格。

## 学习与搜索

`agent/ppo`提供HGNN、PPO优化器及公共worker传输；当前采集和训练控制在`agent/comparators`。A2C、DCAN和Rule-DDQN复用环境及请求接口。训练每批完成20次调度尝试后更新，工程截断保留价值自举；DDQN保持按真实交互学习。

`agent/search`保存搜索预算、优先级与资源排序编码、原生环境解码器、初始化规则、候选评价和Pareto档案。NSGA-II-LS、MOEA/D共享这些实现。编码只提出资源和顺序偏好，合法性、目标和完整轨迹由原生环境确定。预算同时计入初始化、失败评价及局部搜索。

## 评测与记录

训练验证和前沿评价使用20路环境、集中推理及空闲通道续填；独立请求串行测时。采样种子按请求确定，Full的sample1派生自已付费的repeat 0。墙钟与重叠通道时间分列。训练日志、逐例指标、模型、评价原始候选和报告分别保存在一个实验目录下。

`result`包含CSV/JSON写入、epoch日志、权重哈希与控制台显示；`analysis/pareto_analysis.py`仅包含Pareto及HV数学函数。控制台采用启动、训练、验证与结束摘要；每批训练指标分两行显示。

## 检查与身份

pytest验证当前模块和小实例机制；唯一smoke阶段覆盖训练、验证、保存加载、规则和搜索链路。固定数据证书审计按需独立执行。临时输出集中于`.cache/`。

执行身份覆盖算法、环境、数据、有效配置、求解和必要结果计算。文档、测试、报告绘图、控制台显示与PowerShell快捷入口不参与复用判断；预检源码快照包含当前源码、测试、快捷入口和必要配置。不同执行身份使用不同结果目录，完整请求仅在身份匹配时复用。
