## 估计的具体口径

订单预计裕量为 `(horizon_tick - estimated_finish_tick) / horizon_tick`。尚未释放的订单从已知释放 tick 开始估计。对已启动工序使用机器的实际 busy-until tick；对 DIS/INS 使用实际阶段结束 tick，再投影剩余阶段。每条订单的后续选择采用预计完成最早的兼容机器，并维护虚拟机器配置和工人的可用 tick/疲劳，计入同一链中后续工作的占用。

这些是软估计。各订单分别投影，对尚未决定的跨订单重构任务不强加排队顺序；由此产生的竞争及后续策略差异可能使预计完成时间偏乐观。无法安全投影的阶段采用一个 horizon 加一 tick 的有限时长作为风险信号。估计可越过期限，保留负裕量。

工人候选的阶段等待从 WAIT_DIS 的 lock tick 或 WAIT_INS 的 disassembly-end tick 开始，进入下一阶段后重新计时。

WAIT 投影复制可变运行状态，复用实际完成、订单释放和就绪事件处理，更新正在加工/重构的进度及工人疲劳，再计算推进后活跃订单集合的最小裕量。裕量变化等于该最小值减去当前活跃订单的最小值；释放或完成可能改变这个集合。任务终止后，在途工作已经结算，终止观测的 WAIT 时长和裕量变化取 0。
