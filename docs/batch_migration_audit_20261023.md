# 环境、图观测与数据生成迁移审计

日期：2026-10-23。审计对象为当前数据 schema 3、图观测 schema 13 的三因子27例主线。结论：在下述覆盖范围内，物理调度和固定数据正确；发现并修复一个预测特征的顺序依赖问题，以及四项数据/身份校验遗漏。

## 发现与修复

| 项目 | 修复前问题 | 修复 |
|---|---|---|
| 工人重排 | 资源投影在完工时间相同的候选之间按数组下标选工人；只反转工人列表，C01策略logit最大变化约0.001788 | `environment/resource_projection.py` 以稳定工人ID打破平局；物理动作编码不变 |
| 三因子配置 | 改写 `dataset.factor_levels.N` 为[1,2,3]仍生成[12,24,48] | 配置加载、协议哈希和训练计划均核验冻结的27例契约；改变水平需新协议 |
| 图实体ID | 重复机器/工人/模块ID未被数据校验拒绝，可能覆盖索引映射 | 校验非空与唯一性，并拒绝空订单集和空模块标记与真实模块冲突 |
| 在线缓存 | 只解析缓存文件，不验证其内容对应当前索引、种子和生成协议 | 与确定性生成记录逐项核对；同组合内加工时长被改动也会拒绝，不自动覆盖证据 |
| 归一化来源 | 尺度文件虽校验自身哈希，但没有核验其声明的标定集哈希及生成协议 | 实际标定manifest哈希与生成协议必须与尺度来源一致 |

预测特征语义版本从 `order_chain_remaining_context_v3` 更新为 `order_chain_remaining_context_v3_1`。PPO、DCAN、Rule-DDQN 均校验该版本；旧模型需对应旧代码复现或重新训练。数据schema、节点宽度、冻结实例和目标尺度保持原值。源码改变后实验预算身份也随之改变。

缓存核对增加了一次确定性生成开销。本机重建全部108个固定实例约0.47秒，包含读取及对比；这只是局部耗时参考，不代表正式训练吞吐。

## 环境与目标验证

- 全部订单时刻0可用；环境以工序全部完成判定成功。`instance_time_scale` 来自加工下界，仅用于归一化，没有作为终止截止条件。
- 使用27组参数各生成一个新实例，按随机合法动作调度，共25,761次交互，全部完成。完工时间范围105.5～2323.2分钟，超过原240边界仍能正常完成。
- 每条轨迹核对顺序约束、资源占用和疲劳安全；Flow与订单完成时刻之和一致，Excess Flow与Flow减加工下界一致。
- 从拆装日志独立累计固定费用、实际人工费用、机器从锁定到安装完成的停机费用，与环境重构费用一致。工人负荷由实际拆装时长重算，OWA一致；完整轨迹累计奖励满足当前奖励恒等式。
- WAIT投影与复制环境后实际执行同一个合法WAIT的时间、目标状态一致；观测和投影未改变原环境的时间、日志或承诺负荷。

## 图观测验证

- 408个中间状态快照验证有限值、图结构、实际加工/拆装关系及动作索引映射；分组优化生成的加工候选预测，与逐边资源投影一致。
- 不同规模节点特征宽度一致：工序9、机器10、工人7、订单7、模块7；全局11。
- 对C01、C14、C27分别重排模块、机器、工人和订单，映射回原动作后策略logit最大差异不超过约9.7e-8，属于本次浮点计算误差范围。另在实际拆装中的双环境轨迹核对工人重排、策略输出、时间和负荷一致性。
- 旧投影语义的三类学习模型检查点均被拒绝；现行模型预检输出有限。

## 数据验证与解释边界

- 27组合、每组合10个种子，共270个生成实例通过需求平衡、订单模块多样性、初始模块兼容及工人资格检查。
- 标定54、验证27、测试27，共108个冻结实例均由原种子精确重建；去掉实例ID后，108份物理数据也互不重复；三个集合种子无交叉。
- 108个参考证书全部重放通过；3,836个受保护历史文件哈希一致。
- small/medium/large 仍按订单数N分组，K和M在每组内各取三个水平。W和A由M派生，不是额外独立实验因子。
- 机器兼容图采用环加对径边的固定结构，工人资格也有固定构造；随机种子改变标签、参数和工艺路线，不代表覆盖任意兼容图拓扑。
- [8,14]是基础加工时长的整数范围；实际机器加工时长还乘[0.9,1.1]系数并向上量化到0.1分钟，不能把基础范围直接写成所有机器的最终加工时长范围。
- 结构预检是必要条件检查，固定实例的可行性由完整调度证书支持；随机轨迹测试不能替代对所有状态和任意参数的数学证明。
