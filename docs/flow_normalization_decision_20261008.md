# 是否采用 Flow 剩余量归一化

2026-10-08。结论：当前归一化没有正确性缺陷。Flow 剩余量归一化值得作为
Universal 下一轮训练的优先消融，但离线证据尚不足以将它直接确定为正式主方案。
若目的是降低单目标 Flow 的真实完成时间，预期收益比改善 Universal 偏好响应更不确定。

## 必须使用当前方案作为对照

上一轮“总奖励方差降低 41%–67%”的对照是完成时一次抵扣 LB；当前项目
使用原始 Flow，原始 Flow 自身也连续、单调。因此不能把该数字当作修改
当前归一化能获得的方差收益。

本次从上轮 180 个事件轨迹重新构造当前奖励：

`raw = raw_flow + failure_flow_penalty`

`q_old = raw/(1089.15+raw)`

`r_old = diff(progress) - diff(q_old) - failure_reward_penalty`

与相同事件边界上的比例抵扣奖励比较。所有来源调度均用 Flow-only 偏好，
不是 Cost/Variance 模型原始训练奖励；成功与失败分开统计。

| 成功调度来源 | 条数 | excess 保留尺度 1089.15：总奖励方差比中位数 | excess 新尺度 368.3143：总奖励方差比中位数 |
|---|---:|---:|---:|
| full_flow | 57 | 0.9056 | 1.2341 |
| full_cost | 60 | 0.8890 | 1.3061 |

方差比分母均为当前原始 Flow 奖励方差。保留旧尺度时中位数下降约 9%–11%，
采用新尺度时中位数增加约 23%–58%，174 条成功轨迹均增加。6 条失败轨迹
在两种尺度下均增加。方差增加可能来自更强的有效信号，不能直接等同于

## 可证实的收益：扩大相同调度之间的归一化差距

对已有 Universal 的成功重复先在 instance/preference 单元内求 q 均值，再
在同一实例的偏好单元之间取跨度；汇总 20 个实例的跨度中位数。
四种变体使用同一批原始成功调度，Cost/Variance 坐标不变。

| Flow 变换 | 跨偏好跨度中位数 |
|---|---:|
| 当前 F/(1089.15+F) | 0.044584 |
| 只改尺度 F/(368.3143+F) | 0.042460 |
| 只扣 LB，(F-LB)/(1089.15+F-LB) | 0.085352 |
| 扣 LB 并改尺度，(F-LB)/(368.3143+F-LB) | 0.142430 |

只减小原始 Flow 的尺度并没有扩大本批区分度；扣除不可避免的最短加工
时间才是主要方向。比例抵扣使这个终局定义具有连续、单调的中途表达：
等待全额计入，选择较慢机器只计额外时间，最快机器上的必要加工不增加
Flow 剩余量。这给 Flow 目标提供了更直接的损失解释。

上述数字衡量同一批调度的坐标变换，原始 Flow、动作、完成率均没有由此
改善。它不证明重训后偏好响应、收敛速度、HV 或泛化一定改善。
诊断尺度来自验证集，仍需正式标定、冻结和匹配训练检验。

明细：`result/analysis/flow_excess_replay_20261008/normalization_factor_comparison.csv`。
成功重复覆盖率不完全相同，沿用上轮逐单元成功轨迹统计口径。

## 推荐决策

优先进行一个可切换、匹配预算的 Universal 消融：当前原始 Flow 为对照，
比例抵扣并冻结验证尺度为实验臂。两臂使用相同数据、网络、第三目标、
训练预算和采样设置，在同一套原始 Flow/Cost/Variance 评价口径下比较。
跨方法的主 HV 使用同一尺度与参考点，不能把改坐标产生的 HV 变化当改进。

按以下顺序判断是否采用：

1. 完成率和物理可行性至少保持；
2. 增大 Flow 偏好时，原始 Flow 在逐实例比较中更稳定地下降；
3. 原始目标下的 Pareto/HV 或偏好质量改善，且不是简单牺牲 Cost/Variance；
4. 多个训练种子方向一致，收益达到项目设定的实际意义阈值。

若短期要使用已有 checkpoint 完成论文主实验，当前归一化可继续作为
有效基线。若下一轮重点解决 Universal 的 Flow 偏好不敏感，值得优先
实现该消融；其主要预期收益是目标区分度与信用含义，实际调度收益尚待训练。
