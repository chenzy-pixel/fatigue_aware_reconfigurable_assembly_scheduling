# 数学证明文档

本目录按以下顺序组织项目的数学证明。各篇采用独立的定义、命题、证明及公式编号；结论以文中假设和适用范围为准。

| 顺序 | 文档 | 主要结论 |
|---|---|---|
| 1 | [OWA证明](OWA.md) | 严格单调性、均衡转移、平均劳动与集中程度分解、支配一致性 |
| 2 | [Excess Flow 证明](EXCESS.md) | 下界分解、成功调度排序与 Pareto 等价性、比例抵扣过程性质 |
| 3 | [有界标量化与 Pareto 性质证明](SCALARIZATION.md) | 有界性、坐标支配保持、正偏好标量最优解的有效性、零权重边界 |
| 4 | [训练奖励与终局目标一致性证明](REWARD.md) | 进度与承诺结算、回报恒等式、成功失败分离、截断自举 |
| 5 | [动作可行性与疲劳安全不变性证明](SAFETY.md) | 阶段安全、资源与先后约束不变性、部分执行的安全性 |
| 6 | [事件推进与 WAIT 性质证明](EVENT_WAIT.md) | WAIT 进展、有限动作上界、事件积分、受限调度表示及覆盖条件 |
| 7 | [图观测的条件充分性证明](OBSERVATION.md) | 固定实例与精确编码下的状态恢复、奖励与物理转移充分性 |
| 8 | [图网络与偏好策略结构性质证明](NETWORK.md) | 图输入置换性质、共享偏好评分、残差界及条件排序保持 |
| 9 | [三次取优与 checkpoint 选模证明](SELECTION.md) | 交付成功率、候选集内最优性、最差偏好聚合、选模边界及训练目标区别 |

第3篇为第4篇的质量有界性提供依据；第5篇支撑第6篇的成功轨迹可行性；第7篇区分原始状态信息与第8篇的网络表示。第9篇定义当前三次取优及选模，前8篇的相应末节说明其逐轨迹结论如何用于当前协议。

证明中的主要条件如下：

- OWA 的严格均衡偏好使用严格递减正权重；excess 的常数平移等价性限定于固定实例的成功调度。
- 奖励终局恒等式采用固定偏好、固定尺度、无折扣及关闭附加势函数项的当前训练设置。
- 安全定理区分严格数学阈值与代码比较容差，并区分即时安全和全局成功完成。
- WAIT 已证明当前决策系统的进展与有限性；与更宽调度空间的最优值等价需要第6篇列出的额外覆盖条件，该条件尚未由当前证书建立。
- 原始图观测的充分性针对固定实例、固定配置和理想精度；采样保护计数、float32 舍入与网络压缩分别说明。
- 网络置换性质针对已构造图输入及同步变换的动作特征；重建观测时的索引破平局规则不自动满足该条件。

实现对应关系列于各篇末尾。回归测试可核对实现是否符合具体边界案例，不能替代数学证明；训练性能、泛化和 Pareto 前沿覆盖程度由匹配实验评价。

## 当前协议核对（2026-10-16）

主线为 schema12/log2、HGNN shared-head、excess Flow、OWA(q=.5)、gamma=1、GAE lambda=.95，正式评价与选模采用 best_of_3_v1。

| 文档 | 本轮结论与改动 |
|---|---|
| OWA、EXCESS | 原有目标性质和证明保留；补充取优后仍须逐条评价、跨目标重评分保持原生选择 |
| SCALARIZATION | 补充严格正偏好下的成功候选集内非支配性及端点零权重边界 |
| REWARD | 失败系数改记 beta_f，避免与GAE lambda混淆；明确单轨迹回报和交付/选模目标的区别 |
| SAFETY、EVENT_WAIT | 原不变性和有限性证明保留；补充全部原始请求准入及三次请求总预算 |
| OBSERVATION | 原条件充分性证明保留；说明候选选择的外层信息不属于单轨迹critic状态 |
| NETWORK | 将共享评分公式修正为2*tanh(MLP)，保留置换和残差证明，说明逐轨迹对应条件 |
| SELECTION | 新增当前评价与选模的集中证明，包括理想规则、实现容差、历史重算范围 |

真实失败的终局报表Q固定为1，和奖励使用的有界状态Q需区分；PPO轨迹与GAE不执行三选一。原始样本池HV与交付HV也是不同统计量。
