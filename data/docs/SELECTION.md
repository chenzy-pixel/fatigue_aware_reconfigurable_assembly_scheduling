# 三次取优与 checkpoint 选模性质证明

本篇对应 `best_of_3_v1`，补充单轨迹目标、奖励和网络证明与当前评价规则之间的关系。固定实例、偏好、物理配置、目标模式、尺度、策略参数及解码温度；三次采样分别从同一初始状态开始。每条记录必须属于同一个实例—偏好组合，采样序号恰为 0、1、2。

**1．候选选择与准入条件**

记候选为 \(x_r\)，其原生偏好质量为 \(Q_r\)，成功标记为 \(S_r\in\{0,1\}\)。这里 \(S_r\) 对应 `successful_row`：任务完成、没有工程采样截断、没有调度违规，且记录的运行疲劳未超过上限及比较容差。完整原始记录还须通过所选模型的活动约束检查。全疲劳主线要求物理疲劳安全；疲劳中性对照另行报告原始物理暴露。

选择键为：

\[
\boxed{r^*=\operatorname*{arg\,min}_{r\in\{0,1,2\}}
       (1-S_r,Q_r,r)_{\rm lex},\qquad x^*=x_{r^*}.}
\tag{1}
\]

这里 Q_r 对应记录字段 `preference_quality_score`：成功轨迹采用其原生目标和尺度的有界质量；真实任务失败由 `terminal_quality_score` 固定记为1。报表失败分数与奖励证明中的有界状态质量不是同一字段。原生 Q 指产生该候选的目标和尺度下的质量。选择完成后重评分时保持同一 \(r^*\)；若改变尺度或目标后重新选择，属于另一项实验。

缺失、重复、混合实例/偏好或工程截断不构成完整正式评价。任何原始请求的活动约束或调度违规不能因未被选中而被过滤。真实期限失败或死锁可以作为完整评价中的失败样本；工程截断保留未完成的采样，二者不同。

**2．逐组合成功与质量保证**

**命题1．** 选择结果满足：

\[
\boxed{S^*=\max_r S_r.}
\tag{2}
\]

若至少一个候选成功，则：

\[
\boxed{Q^*=\min_{r:S_r=1}Q_r.}
\tag{3}
\]

若全部失败，则所选记录仍计作失败，仅按报表 Q、序号确定保留哪份失败记录；三份均为真实任务失败时 Q 均为1，最终保留采样序号最小者。

**证明．** 字典序先比较 \(1-S_r\)，任何成功候选都优先于失败候选；在最小首坐标内再比较 Q 和序号，直接得到式（2）、（3）。证毕。

对包含同一首份样本的候选集合，式（2）给出成功标记不低于该样本；当该首份样本成功时，式（3）给出所选 Q 不高于它。这是同一候选集合中的路径级保证，不证明每个原始目标均改善，也不能用于不同随机样本之间的逐例保证。

在额外假设三次成功事件条件独立、且单次成功概率均为 p 时：

\[
\Pr(S^*=1)=1-(1-p)^3.
\tag{4}
\]

**证明．** 交付失败当且仅当三次均失败，独立性给出其概率为 \((1-p)^3\)。证毕。没有独立性时只能写成 \(1-\Pr(S_0=S_1=S_2=0)\)；配置三个不同固定种子本身不构成独立性的数学证明。

**3．候选集内 Pareto 性质**

**命题2．** 固定严格正偏好、正尺度及 \(\rho>0\)。若成功候选集合非空，则式（1）的交付在该成功候选集合的完整三目标向量下非支配。

**证明．** 若另一成功候选支配交付，[标量化证明](SCALARIZATION.md)命题3给出其 Q 严格更低，与式（3）矛盾。证毕。

该结论的集合仅为实际采样到的成功候选。存在零权重时，某些坐标的改善可能不改变 Q，按采样序号破平局可能保留在被忽略坐标上较差的候选，故不能推广到全部偏好端点。也不能推广为全部可行调度上的 Pareto 最优性或前沿覆盖保证。

**4．Universal 聚合与 checkpoint 比较**

设固定验证集为 \(\mathcal I\)，偏好网格为 \(\Omega\)，每个组合独立形成一份交付。对 checkpoint c 定义：

\[
C_{c,\omega}=\frac1{|\mathcal I|}\sum_{i\in\mathcal I}S^*_{c,i,\omega},
\qquad C_c=\min_{\omega\in\Omega}C_{c,\omega}.
\tag{5}
\]

每个偏好的质量只在成功交付中平均：

\[
q_{c,\omega}=\begin{cases}
\displaystyle\frac{\sum_i S^*_{c,i,\omega}Q^*_{c,i,\omega}}
{\sum_i S^*_{c,i,\omega}},&\sum_i S^*_{c,i,\omega}>0,\\
+\infty,&\text{否则},
\end{cases}
\quad \overline Q_c=\frac1{|\Omega|}\sum_{\omega\in\Omega}q_{c,\omega}.
\tag{6}
\]

仅完整且满足全部原始请求活动约束的 checkpoint 进入比较。理想零容差规则在实际检查过的合格 checkpoint 中最小化 \((-C_c,\overline Q_c)\)，完全相同则保留更早者。单目标取 \(|\Omega|=1\)，此时 C 是整体完成率。

**命题3．** 在零容差比较下，逐个维护当前最佳值与对全部已见合格候选取上述字典序最小值等价。

**证明．** 首个合格候选初始化最小值；归纳假设当前保存此前最小值，新候选更优时替换，否则保留。完全相同不替换，保留最早候选。证毕。

实际 `LexicographicCheckpointSelector` 使用 \(\varepsilon=10^{-12}\)：完成率大于当前值加容差即改善；完成率差在容差内时，Q 必须低于当前值减容差才替换。它是带容差的顺序规则；近似相等关系一般不具有传递性，不能把命题3不加说明地称为任意浮点输入下的精确全局排序。当前固定验证规模的完成率步长远大于该容差，但 Q 仍按实现容差比较。

式（6）不是平均目标向量的 Q。由于成功集合可能不同，式（3）也不保证整体成功条件平均 Q 必然下降：两实例中首份样本只有一个成功、Q=0.1；增加候选后该实例仍取0.1，另一实例新获得成功、Q=0.9，则完成率从1/2变为1，而成功条件平均 Q 从0.1变为0.5。比较目标改善应同时报告完成覆盖及共同成功实例上的配对差异。

**5．训练目标与交付目标的区别**

当前 PPO 继续使用原始采集轨迹、原奖励和 GAE。[奖励证明](REWARD.md)的 \(G=1-Q\) 对每条成功轨迹成立。在三条候选全成功时，式（3）给出：

\[
G^*=1-\min_r Q_r=\max_r G_r.
\tag{7}
\]

但最大化单次期望回报与最大化三次取优期望回报并不等价。例如，考虑均成功的抽象质量分布：甲恒取0.2；乙等概率取0.1或0.4。单次平均 Q 为0.2与0.25，甲更优；独立三次取优后，乙的平均 Q 为 \(0.1\cdot7/8+0.4\cdot1/8=0.1375\)，乙更优。这是目标排序可能改变的反例，不是当前模型的实测性能断言。

存在真实失败时，奖励还包含进度和失败罚项。三份均真实失败时终局报表 Q 均为1，选择由采样序号决定，不必等同于按失败回报 \(P-Q^{\mathrm{reward}}-\beta_f\) 取最大。critic 的截断自举估计单轨迹续接价值，并不估计剩余若干采样机会的最佳交付价值。

**6．新协议训练与历史复算**

固定一个已保存 checkpoint，对其现有完整三次记录执行式（1）—（6），可以验证该权重在新聚合口径下的记录表现。利用历次完整验证日志也可以找出新口径偏好的验证 episode。

这两项操作不等于完成新协议训练：被新规则选中的中间权重可能没有保存；当前学习率平台控制还由 best 改善事件驱动，新选模会改变未来学习率、参数和轨迹。最终测试只评价验证选出的模型，不能用测试结果反向选择 episode、q、lambda 或尺度。

**7．预算与实现对应**

在best_of_3_v1下，每个实例—偏好组合为三次请求、一份交付。预算统计累计全部请求的推理、仿真、决策和工人时间；原始样本池 Pareto/HV 与每偏好一份交付的 Pareto/HV 应分开命名。三次PPO采样与给定时限内的搜索属于不同预算定义，不因都输出一份方案而成为同预算比较；旧300次候选评价不是当前已冻结的正式搜索预算。

实现对应：[候选选择](../../result/sample_selection.py)、[成功标记](../../result/metrics.py)的 successful_row、[正式聚合与活动约束](../../train.py)的 _aggregate_formal_rows / _rows_satisfy_active_constraints，以及 [checkpoint 选择](../../training/protocol.py)。[操作协议](../../docs/default_best_of_three.md)说明记录文件与历史身份；[实验清单](../../docs/experiment_runlist.md)列出验证这些边界的实验。
