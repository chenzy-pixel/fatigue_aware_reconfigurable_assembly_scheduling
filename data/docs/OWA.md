# OWA证明

设 \(\mathcal X\) 为满足全部生产任务、资源约束及疲劳安全约束的可行调度集合，工人数为 \(H\ge2\)。对于调度 \(x\in\mathcal X\)，工人 \(h\) 的实际劳动负荷定义为其执行全部拆卸与安装任务的实际作业时间之和：

\[
L_h(x)=\sum_{j\in\mathcal R_h(x)}d_j(x),
\qquad h=1,\ldots,H,
\]

其中，\(\mathcal R_h(x)\) 为分配给工人 \(h\) 的重构阶段集合，\(d_j(x)\) 为阶段 \(j\) 的实际持续时间。未承担重构任务的工人满足 \(L_h(x)=0\)。定义总劳动量与平均劳动负荷：

\[
T(x)=\sum_{h=1}^{H}L_h(x),
\qquad
\bar L(x)=\frac{T(x)}{H}.
\]

**1．有序加权劳动负荷目标**

将负荷向量按降序排列：

\[
L_{(1)}(x)\ge L_{(2)}(x)\ge\cdots\ge L_{(H)}(x)\ge0.
\]

定义有序加权平均负荷目标：

\[
\boxed{
G_w(x)=\sum_{i=1}^{H}w_iL_{(i)}(x)
}
\tag{1}
\]

其中权重满足：

\[
w_1>w_2>\cdots>w_H>0,
\qquad
\sum_{i=1}^{H}w_i=1.
\tag{2}
\]

权重与负荷排名对应，因此 \(G_w\) 对工人编号的置换保持不变。递减权重使较高负荷获得更大的边际权重，而严格正权重保证所有工人的劳动负荷均参与评价。

采用几何权重时：

\[
\boxed{
w_i(q)=
\frac{(1-q)q^{i-1}}{1-q^H},
\qquad 0<q<1.
}
\tag{3}
\]

参数 \(q\) 控制不同负荷排名之间的权重差异。对于固定 \(H\)：

\[
\lim_{q\to0^+}G_{w(q)}(x)
=
\max_hL_h(x),
\qquad
\lim_{q\to1^-}G_{w(q)}(x)
=
\bar L(x).
\tag{4}
\]

因此，几何 OWA 在最大个人劳动负荷与平均劳动负荷之间提供连续的偏好调节。

**2．严格单调性**

传统负荷方差为：

\[
V(L)=\frac1H\sum_{h=1}^{H}(L_h-\bar L)^2.
\tag{5}
\]

其关于单个工人负荷的偏导数为：

\[
\frac{\partial V}{\partial L_h}
=
\frac2H(L_h-\bar L).
\tag{6}
\]

当 \(L_h<\bar L\) 时，增加该工人的少量劳动会降低方差。因此，在总劳动量可变的调度问题中，方差可能将额外劳动解释为均衡改善。

**命题1．** 对满足式（2）的权重，\(G_w\) 关于负荷向量具有严格单调性。即对于 \(u,v\in\mathbb R_+^H\)，若

\[
u_h\le v_h,\qquad \forall h,
\]

且至少一个不等式严格成立，则：

\[
G_w(u)<G_w(v).
\tag{7}
\]

**证明．** 逐坐标关系 \(u_h\le v_h\) 蕴含相应降序统计量满足：

\[
u_{(i)}\le v_{(i)},\qquad \forall i.
\]

令 \(\delta_i=v_{(i)}-u_{(i)}\ge0\)。由于排序不改变元素之和：

\[
\sum_{i=1}^{H}\delta_i
=
\sum_{h=1}^{H}(v_h-u_h)>0.
\]

结合 \(w_i>0\)，得到：

\[
G_w(v)-G_w(u)
=
\sum_{i=1}^{H}w_i\delta_i>0.
\]

证毕。

进一步，由 \(w_H\le w_i\le w_1\)，有：

\[
\boxed{
w_H\sum_h(v_h-u_h)
\le
G_w(v)-G_w(u)
\le
w_1\sum_h(v_h-u_h).
}
\tag{8}
\]

特别地，若仅对工人 \(h\) 增加 \(d>0\) 单位劳动，则：

\[
\boxed{
w_Hd
\le
G_w(L+de_h)-G_w(L)
\le
w_1d,
}
\tag{9}
\]

其中 \(e_h\) 为第 \(h\) 个单位向量。该结论不要求增加劳动前后的负荷排名保持不变。

**3．固定总劳动量下的均衡转移性质**

定义最高负荷的前 \(k\) 位工人的累计劳动量：

\[
S_k(L)=\sum_{i=1}^{k}L_{(i)},
\qquad k=1,\ldots,H.
\tag{10}
\]

其中 \(S_H(L)=T\)。由求和重排可得：

\[
\boxed{
G_w(L)
=
w_HT+
\sum_{k=1}^{H-1}(w_k-w_{k+1})S_k(L).
}
\tag{11}
\]

式（11）中，\(L_{(i)}\) 的系数为：

\[
w_H+\sum_{k=i}^{H-1}(w_k-w_{k+1})=w_i,
\]

因此该表示与式（1）等价。

考虑两位工人 \(a,b\)，满足 \(L_a>L_b\)。将 \(d\) 单位劳动由工人 \(a\) 转移给工人 \(b\)，其中：

\[
0<d\le\frac{L_a-L_b}{2}.
\tag{12}
\]

转移后的负荷向量为：

\[
L'=L-de_a+de_b.
\tag{13}
\]

该转移保持总劳动量不变，并缩小两位工人的负荷差距。

**命题2．** 对上述非零均衡转移，有：

\[
G_w(L')<G_w(L).
\tag{14}
\]

**证明．** 对任意 \(k\)，累计最高负荷可表示为：

\[
S_k(L)=
\max_{\substack{A\subseteq\{1,\ldots,H\}\\|A|=k}}
\sum_{h\in A}L_h.
\]

若集合 \(A\) 同时包含或同时不包含 \(a,b\)，其负荷和不变；若仅包含 \(a\)，其负荷和减少 \(d\)；若仅包含 \(b\)，则可用包含 \(a\) 而不包含 \(b\) 的集合比较。由于 \(d\le L_a-L_b\)，仍有：

\[
S_k(L')\le S_k(L),
\qquad k=1,\ldots,H-1.
\tag{15}
\]

此外：

\[
\sum_hL_h^2-\sum_h(L'_h)^2
=
2d(L_a-L_b-d)>0.
\tag{16}
\]

因此，转移前后的排序负荷向量不相同。在总量相同的条件下，式（15）至少有一项严格成立。结合 \(w_k-w_{k+1}>0\) 与式（11），得到：

\[
G_w(L')-G_w(L)
=
\sum_{k=1}^{H-1}(w_k-w_{k+1})
\bigl[S_k(L')-S_k(L)\bigr]
<0.
\]

证毕。

该性质表明，OWA 不仅关注最大负荷，而且对任意两位负荷不同工人之间的均衡转移均具有严格偏好。

**4．平均劳动与负荷集中程度的分解**

归一化条件给出：

\[
Hw_H+
\sum_{k=1}^{H-1}k(w_k-w_{k+1})
=
1.
\tag{17}
\]

将式（17）代入式（11），得到：

\[
\boxed{
G_w(L)=\bar L+D_w(L),
}
\tag{18}
\]

其中：

\[
\boxed{
D_w(L)=
\sum_{k=1}^{H-1}(w_k-w_{k+1})
\left[S_k(L)-k\bar L\right].
}
\tag{19}
\]

由于负荷按降序排列：

\[
\frac{S_k(L)}{k}\ge\bar L,
\]

因此：

\[
D_w(L)\ge0.
\tag{20}
\]

当权重严格递减时：

\[
D_w(L)=0
\iff
L_1=\cdots=L_H.
\tag{21}
\]

由此，OWA 可解释为**平均实际劳动负荷与负荷集中惩罚之和**。在总量固定时，它偏好均衡分配；在总量变化时，它同时计入劳动总量与分配结构的变化。

对于局部排名不变的负荷调整，若较高负荷位置 \(i\) 减少 \(a>0\) 单位劳动，较低负荷位置 \(j>i\) 增加 \(b>0\) 单位劳动，则：

\[
\Delta G_w=-w_ia+w_jb.
\tag{22}
\]

因此：

\[
\boxed{
\Delta G_w<0
\iff
\frac ba<\frac{w_i}{w_j}.
}
\tag{23}
\]

对于几何权重：

\[
\frac{w_i}{w_j}=q^{\,i-j}.
\tag{24}
\]

式（23）说明，OWA 允许以一定的额外劳动代价实现负荷重分配，同时通过权重比限制这种交换的目标收益。该局部关系以其他负荷不变且排名不变为前提。

**5．与逐工人负荷支配关系的一致性**

定义两个多目标映射：

\[
\Phi_L(x)=
\bigl(F(x),C(x),L_1(x),\ldots,L_H(x)\bigr),
\tag{25}
\]

\[
\Phi_G(x)=
\bigl(F(x),C(x),G_w(x)\bigr),
\tag{26}
\]

所有目标均最小化。分别以 \(\mathcal E_L\) 和 \(\mathcal E_G\) 表示二者在同一可行调度集合 \(\mathcal X\) 上的非支配调度集合。

**命题3．**

\[
\boxed{
\mathcal E_G\subseteq\mathcal E_L.
}
\tag{27}
\]

**证明．** 假设存在 \(x\in\mathcal E_G\) 但 \(x\notin\mathcal E_L\)。则存在 \(y\in\mathcal X\)，满足：

\[
F(y)\le F(x),\qquad
C(y)\le C(x),\qquad
L_h(y)\le L_h(x)\quad\forall h,
\tag{28}
\]

且至少一项严格成立。

若劳动向量中至少一项严格改善，由命题1可得：

\[
G_w(y)<G_w(x).
\]

若劳动向量完全相同，则 \(G_w(y)=G_w(x)\)，且至少 \(F\) 或 \(C\) 严格改善。两种情况下，\(y\) 均在 \(\Phi_G\) 下支配 \(x\)，与 \(x\in\mathcal E_G\) 矛盾。证毕。

因此，采用 OWA 后，真正的三目标非支配集合不会包含在流动时间、成本及所有工人劳动负荷上均存在更优替代的调度。该结论同样适用于任意固定有限候选集上的精确非支配筛选，但不直接保证近似学习算法输出的每条轨迹均为非支配解。

**6．增量奖励与终局目标的一致性**

设决策步为 \(t=0,\ldots,K\)，已承诺劳动负荷为 \(L^c_t\)。对于工人 \(h\) 的一次阶段分派，若冻结工期为 \(d_t>0\)，则：

\[
L^c_{t+1}=L^c_t+d_te_h.
\tag{29}
\]

定义：

\[
G_t=G_w(L^c_t),
\qquad
r_t^G=-(G_{t+1}-G_t).
\tag{30}
\]

在无折扣累计回报下：

\[
\boxed{
\sum_{t=0}^{K-1}r_t^G=G_0-G_K.
}
\tag{31}
\]

若初始累计劳动为零，且成功终止时承诺负荷与实际负荷一致，则：

\[
\boxed{
\sum_{t=0}^{K-1}r_t^G=-G_w(L(x)).
}
\tag{32}
\]

由式（9），每次新增劳动对应：

\[
-w_1d_t\le r_t^G\le-w_Hd_t<0.
\tag{33}
\]

排名变化不影响式（31）的相消性质，但每一步均须依据更新后的完整负荷向量重新计算 OWA。若失败终止时撤回未执行的承诺劳动，式（31）仍成立，但式（33）的单步符号结论不适用于该结算步骤，且失败应由独立的失败机制处理。

采用固定正尺度 \(s_G\) 进行归一化：

\[
z_G(G)=\frac{G}{s_G+G},
\qquad s_G>0,
\tag{34}
\]

其导数为：

\[
z_G'(G)=\frac{s_G}{(s_G+G)^2}>0.
\tag{35}
\]

因此，该变换保留 OWA 的严格单调性及其目标排序。相邻状态的归一化增量满足：

\[
z_G(G_{t+1})-z_G(G_t)
=
\frac{s_G(G_{t+1}-G_t)}
{(s_G+G_t)(s_G+G_{t+1})}.
\tag{36}
\]

若以完整多目标标量化质量 \(Q_t\) 构造奖励：

\[
r_t=(P_{t+1}-P_t)-(Q_{t+1}-Q_t)-c_t^{\mathrm{fail}},
\tag{37}
\]

则在折扣因子 \(\gamma=1\) 时：

\[
\boxed{
\sum_{t=0}^{K-1}r_t
=
P_K-P_0+Q_0-Q_K
-
\sum_{t=0}^{K-1}c_t^{\mathrm{fail}}.
}
\tag{38}
\]

由此，将 OWA 接入质量函数的劳动负荷坐标，可以同时保持逐步奖励计算与终局优化目标的一致性。

**7．三次取优与当前选模协议**

前述命题描述单份调度的实际劳动向量及目标函数，shared-head 的参数化和 checkpoint 的选择方式不改变这些数学性质。三次取优返回三份候选中的一份；对其实际劳动向量仍可直接应用命题1—3。

选择依据为完整原生质量 Q，而非单独最小化 OWA；Flow/Cost/OWA 的权衡可能使获选方案的某个单项变差。也不能用“平均劳动向量的 OWA”替代“逐份交付 OWA 的平均值”。完整候选选择、成功条件及候选集内 Pareto 边界见 [三次取优与选模证明](SELECTION.md)。式（38）继续逐轨迹成立，PPO 的训练样本和 GAE 不按三选一筛选。
