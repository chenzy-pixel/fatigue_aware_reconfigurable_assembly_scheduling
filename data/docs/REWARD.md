# 训练奖励与终局目标一致性证明

设固定实例有 \(N\ge1\) 个订单，订单 \(j\) 含 \(n_j\ge1\) 道工序。所有订单及其工序在初始化时已知，释放时间可以不同。以 \(k=0,\ldots,K\) 表示决策状态序号，以 \(t_k\) 表示对应的物理时刻；不同决策状态可以具有相同的物理时刻。

以下采用固定偏好、固定目标尺度及折扣因子 \(\gamma=1\)，并令可选可行性势函数项关闭。质量函数 \(Q_k\) 使用 [有界标量化证明](SCALARIZATION.md) 中的定义，故 \(0\le Q_k<1\)。

**1．订单平衡进度与承诺劳动**

令 \(c_j(k)\) 为状态 \(k\) 中订单 \(j\) 已完成的工序数，定义：

\[
P_k=\frac1N\sum_{j=1}^N\frac{c_j(k)}{n_j}.
\tag{1}
\]

**命题1．** \(0\le P_k\le1\)，且 \(P_k=1\) 当且仅当全部工序完成。仅释放订单而不完成工序，不改变 \(P_k\)。

**证明．** 每一项 \(c_j(k)/n_j\) 属于 \([0,1]\)，其均值也属于该区间。均值等于一当且仅当所有项均等于一，即各订单的所有工序均完成。订单释放不改变初始化时固定的 \(N,n_j\)，也不改变 \(c_j(k)\)，因此不产生进度增量。证毕。

令 \(L_h^f(k)\) 为工人 \(h\) 已结算的实际劳动时间，\(\mathcal A_h(k)\) 为其活动阶段集合，\(d_a\) 为阶段开始时冻结的完整工期。决策过程中使用：

\[
L_h^c(k)=L_h^f(k)+\sum_{a\in\mathcal A_h(k)}d_a.
\tag{2}
\]

当前资源约束使 \(|\mathcal A_h(k)|\le1\)。劳动目标由完整承诺负荷向量计算，而非由各工人的已结算负荷近似计算。

**命题2．** 分派时增加完整承诺、完成时将同一完整工期转入实际负荷、真实失败时撤回未执行部分，则式（2）在非终止状态成立；成功终局的承诺负荷等于实际负荷。

**证明．** 初始无活动阶段，两者相等。分派阶段时，右端活动工期增加 \(d_a\)，承诺账本同时增加 \(d_a\)。阶段完成时，右端已结算劳动增加 \(d_a\)，活动集合移除该阶段，两项变化相消，因此完成本身不重复增加承诺负荷。失败时若仅执行 \(\tau_a\le d_a\)，实际负荷增加 \(\tau_a\)，承诺负荷扣除 \(d_a-\tau_a\)，清除该活动承诺后两者一致。成功时所有活动阶段均完成，式（2）的求和项为零。证毕。

**2．完整奖励的望远镜恒等式**

令 \(I_k=1\) 表示第 \(k\) 次转移首次进入真实任务失败终局，否则为零。记 \(I=\sum_{k=0}^{K-1}I_k\in\{0,1\}\)，失败罚系数为 \(\beta_f\ge0\)。定义：

\[
\boxed{
r_k=(P_{k+1}-P_k)+(Q_k-Q_{k+1})-\beta_f I_k.
}
\tag{3}
\]

**命题3．** 任意有限轨迹前缀均满足：

\[
\boxed{
G_K:=\sum_{k=0}^{K-1}r_k
=P_K-P_0+Q_0-Q_K-\beta_f I.
}
\tag{4}
\]

**证明．** 分别对式（3）的三项求和。相邻进度项及质量项逐项抵消，失败指示之和为 \(I\)，故：

\[
\sum_{k=0}^{K-1}(P_{k+1}-P_k)=P_K-P_0,\qquad
\sum_{k=0}^{K-1}(Q_k-Q_{k+1})=Q_0-Q_K.
\tag{5}
\]

代回即得式（4）。该抵消不要求物理时间严格增加，也不要求各步质量单调变化。证毕。

**推论1．** 标准从零初始化满足 \(P_0=Q_0=0\)。成功终局有 \(P_K=1,I=0\)，由命题2，其劳动目标为终局实际劳动目标，因而：

\[
\boxed{G_K=1-Q_{\boldsymbol\omega}(\boldsymbol J(x)).}
\tag{6}
\]

因此，在固定实例、固定偏好的成功调度集合上，最大化累计回报与最小化终局质量具有相同的最优解集合。对几乎必然成功且期望存在的策略，同样有 \(\mathbb E[G_K]=1-\mathbb E[Q_K]\)；这里优化的是质量分数的期望，通常不等于对原始目标期望进行标量化。

**3．成功与失败的回报分离**

**命题4．** 在标准初始化及式（3）下，任意成功轨迹满足 \(0<G_K\le1\)，任意失败轨迹满足：

\[
-1-\beta_f<G_K\le1-\beta_f.
\tag{7}
\]

特别地，\(\beta_f\ge1\) 足以使每条成功轨迹的回报严格大于每条失败轨迹的回报；当前 \(\beta_f=2\) 给出失败回报上界 \(-1\)。

**证明．** 成功时由式（6）及 \(0\le Q_K<1\) 得到结论。失败时由式（4）：

\[
G_K=P_K-Q_K-\beta_f,
\tag{8}
\]

结合 \(0\le P_K\le1\)、\(0\le Q_K<1\)，得到式（7）。若 \(\beta_f\ge1\)，失败回报至多为零，而成功回报严格为正。证毕。

此处的分离针对单条轨迹。它不推出任意随机策略之间都按成功概率作严格字典序排序。例如，抽象回报分布甲以概率 \(1\) 获得成功回报 \(0.1\)，乙以概率 \(0.99\) 获得成功回报 \(0.9\)、以概率 \(0.01\) 获得失败回报 \(-2\)，则：

\[
\mathbb E[G_{\rm 甲}]=0.1,\qquad
\mathbb E[G_{\rm 乙}]=0.99\times0.9-0.01\times2=0.871.
\tag{9}
\]

两分布均符合上述回报界，但成功概率较低者具有更高期望回报。该例说明回报界本身不足以推出策略层面的字典序性质，并不声称这两分布由某个具体实例产生。项目的完成率优先选模属于独立的评价规则。

**4．工程截断与价值自举**

令 \(V^\pi(S_K)\) 为状态 \(S_K\) 在策略 \(\pi\) 下后续累计奖励的条件期望。若采样在非终止状态 \(K\) 截断，则条件期望的可加性给出：

\[
\boxed{
\mathbb E^\pi[G_T\mid\mathcal H_K]
=G_K+V^\pi(S_K),
}
\tag{10}
\]

其中 \(\mathcal H_K\) 为包含已执行动作的完整前缀历史，\(T\) 为后续真实终止步；要求策略基于充分状态决策，且相关期望存在。

**证明．** 将完整回报分解为已观测前缀与剩余回报。前缀在给定历史下为常数，剩余回报的条件期望由状态充分性及策略假设等于 \(V^\pi(S_K)\)。证毕。

真实任务终止时后续回报为零，故自举值为零。工程截断保留非终止状态，应估计其后续价值；把它设为零会遗漏式（10）的第二项。实际 critic 是近似值，GAE 还使用优势递推，因此式（10）不宣称实际估计无误差或 GAE 在任意参数下无偏。

**5．折扣与附加势函数的适用范围**

记 \(U_k=P_k-Q_k\)。当 \(0<\gamma<1\) 时，差分项的折扣和为：

\[
\sum_{k=0}^{K-1}\gamma^k(U_{k+1}-U_k)
=-U_0+\gamma^{K-1}U_K
+(1-\gamma)\sum_{j=1}^{K-1}\gamma^{j-1}U_j.
\tag{11}
\]

该式由分别移动两项求和指标得到，明确包含中间状态项，故式（6）不能直接用于折扣回报。当前训练采用 \(\gamma=1\)。

若另加入固定系数的势函数差分 \(\eta(\Phi_{k+1}-\Phi_k)\)，则式（4）右端还需加入：

\[
\eta(\Phi_K-\Phi_0).
\tag{12}
\]

只有在所比较轨迹的该端点差为常数等条件下，才能进一步保持原有排序。本文奖励等价性及回报界对应当前关闭该项的配置。

实现对应为 [环境奖励及负荷结算](../../environment/env.py) 中的 step、operation_progress、_finish_committed_worker_task、_settle_committed_worker_task，[标量奖励](../../environment/types.py) 中的 RewardVector，以及 [GAE 递推](../../agent/ppo/buffer.py)。

**6．单轨迹训练与三次取优选模**

本篇失败罚系数 \(\beta_f=2\)，与优势估计中的 GAE \(\lambda=.95\) 是不同参数。式（4）对每条训练、验证或测试轨迹分别成立。三次取优在完整候选集合之外增加选择步骤，PPO buffer、奖励和 GAE 保留原始采集轨迹，critic 仍估计单条策略续接的价值。

对固定实例/偏好，若三份候选全成功，获选轨迹满足 G*=1-min_r Q_r=max_r G_r；这不表示当前 PPO 在优化三次采样最大回报的期望。含真实失败时，候选选择首先比较成功标记，真实任务失败的终局报表分数固定为1，三份均真实失败时按采样序号保留，可能与按 \(P-Q-\beta_f\) 的训练回报排序不同。最差偏好完成率和成功条件平均 Q 的 checkpoint 规则也不是期望训练回报的字典序表达。具体定义及反例见 [三次取优与选模证明](SELECTION.md)。
