# 有界标量化与 Pareto 性质证明

设 \(\mathcal X\) 为固定实例的可行调度集合，所有目标均最小化。对 \(x\in\mathcal X\)，目标向量记为 \(\boldsymbol J(x)=(J_1(x),\ldots,J_d(x))\in\mathbb R_+^d\)，且各目标有限。本项目取 \(d=3\)，分别对应所选 Flow、重构成本和劳动负担目标。以下尺度及偏好在比较过程中保持不变。

**1．有界坐标变换与质量函数**

给定固定尺度 \(s_i>0\)，定义：

\[
z_i(J_i)=\frac{J_i}{s_i+J_i},\qquad
\boldsymbol\omega\in\Delta^{d-1}
=\left\{\boldsymbol\omega:\omega_i\ge0,\ \sum_i\omega_i=1\right\}.
\tag{1}
\]

增强切比雪夫质量函数为：

\[
\boxed{
Q_{\boldsymbol\omega}(\boldsymbol J)
=\frac{\max_i\{\omega_i z_i(J_i)\}
+\rho\sum_i\omega_i z_i(J_i)}{1+\rho},
\qquad \rho\ge0.
}
\tag{2}
\]

这里的“质量”是待最小化分数。尺度决定不同目标的数值敏感度，偏好决定各目标在标量器中的权重。

**命题1．** 对有限非负目标，式（1）严格递增且满足 \(0\le z_i<1\)；式（2）满足 \(0\le Q_{\boldsymbol\omega}<1\)。

**证明．** 直接计算得到：

\[
z_i'(J_i)=\frac{s_i}{(s_i+J_i)^2}>0,\qquad
J_i=s_i\frac{z_i}{1-z_i}.
\tag{3}
\]

因此式（1）在 \(\mathbb R_+\) 上可逆，值域为 \([0,1)\)。由于偏好非负且和为一，至少一个偏好严格为正，从而：

\[
0\le\sum_i\omega_i z_i<1,\qquad
0\le\max_i(\omega_i z_i)\le\sum_i\omega_i z_i<1.
\tag{4}
\]

代入式（2）即得 \(0\le Q_{\boldsymbol\omega}<1\)。证毕。

**2．坐标变换对支配关系的保持**

称 \(x\) 支配 \(y\)，若 \(J_i(x)\le J_i(y)\) 对所有 \(i\) 成立，且至少一项严格成立。

**命题2．** 采用固定正尺度的式（1），保持调度之间的 Pareto 支配关系及非支配集合。

**证明．** 由式（3），对每个坐标均有：

\[
J_i(x)\le J_i(y)
\iff z_i(J_i(x))\le z_i(J_i(y)),
\tag{5}
\]

且严格不等关系也等价。逐坐标应用式（5），支配关系的全部条件在变换前后相同，故非支配集合相同。证毕。

**推论1．** 在同一实例的成功调度集合上，先以 excess 替换 raw Flow，再对各坐标作式（1）的变换，仍保持 Pareto 支配关系。第一步使用 [Excess Flow 证明](EXCESS.md) 中的实例常数平移结论，第二步使用命题2。

该结论不要求 raw 与 excess 使用相同尺度，但两套尺度各自必须固定且严格为正。它不保证变换前后具有相同的标量化最优解或相同的超体积数值。

**3．严格正偏好下的 Pareto 有效性**

**命题3．** 若 \(\omega_i>0\) 对所有 \(i\) 成立，且 \(\rho>0\)，则式（2）严格尊重支配关系：

\[
x\text{ 支配 }y
\Longrightarrow
Q_{\boldsymbol\omega}(\boldsymbol J(x))
<
Q_{\boldsymbol\omega}(\boldsymbol J(y)).
\tag{6}
\]

因此，只要标量问题的全局最小值能够达到，其任意全局最优解均为 Pareto 有效解。

**证明．** 支配关系及命题2给出：

\[
\omega_i z_i(J_i(x))\le\omega_i z_i(J_i(y)),
\quad\forall i,
\qquad
\sum_i\omega_i z_i(J_i(x))
<
\sum_i\omega_i z_i(J_i(y)).
\tag{7}
\]

最大项不增，和项严格减小。结合 \(\rho>0\)，即得式（6）。若某个全局最优解被其他可行解支配，则式（6）说明后者具有更小质量分数，与全局最优性矛盾。证毕。

**命题4．** 当 \(\rho=0\) 且各偏好严格为正时，任意全局最优解至少是弱 Pareto 有效解，即不存在全部目标均严格更小的可行解。

**证明．** 若全部目标严格改善，则全部 \(\omega_i z_i\) 严格减小。取改善后最大项所在坐标 \(k\)，有：

\[
\max_i\omega_i z_i(J_i(x))
=\omega_k z_k(J_k(x))
<\omega_k z_k(J_k(y))
\le\max_i\omega_i z_i(J_i(y)).
\tag{8}
\]

故被全部坐标严格改善的解不能是全局最优解。证毕。

仅有部分坐标严格改善时，最大项可能不变。例如等权重下，归一化目标由 \((0.8,0.4)\) 改善为 \((0.8,0.2)\)，未增强的最大项相同。这说明增强项对严格支配一致性具有实际作用。

**4．零权重偏好的边界**

令 \(A=\{i:\omega_i>0\}\)。式（2）只依赖 \(A\) 中的坐标；当 \(\rho>0\) 时，命题3仅能排除在这些坐标上被支配的最优解。

**命题5．** 允许零权重时，标量全局最优解未必是完整目标向量的 Pareto 有效解。

**证明．** 取两个可行解的归一化向量为 \(u=(0.2,0.8,0.8)\)、\(v=(0.2,0.1,0.1)\)，并取 \(\boldsymbol\omega=(1,0,0)\)。对任意 \(\rho\ge0\)，二者质量分数均为 \(0.2\)。在仅由这两个解构成的可行集中，二者都是标量最优解，但 \(u\) 被 \(v\) 支配。证毕。

因此，端点偏好可用于训练单目标方向，但完整 Pareto 集仍应按全部目标进行非支配筛选。有限偏好网格与近似学习求解也不构成前沿完整覆盖的保证。

**5．观测编码与数值边界**

schema12 的两种累计目标输入为：

\[
e_{\log}(J)=\log_2(1+J/s),\qquad
e_{\mathrm b}(J)=J/(s+J).
\tag{9}
\]

二者在理想实数精度下均严格递增且可逆，其逆变换分别为：

\[
J=s(2^{e_{\log}}-1),\qquad
J=s\frac{e_{\mathrm b}}{1-e_{\mathrm b}}.
\tag{10}
\]

这说明仅从精确标量编码看，二者都保留该坐标的信息。浮点舍入可能使不同输入映射到相同数值，尤其有界编码可能舍入为 \(1\)；式（10）不构成对 float32 可逆性的保证。改变观测编码不改变式（2），其训练效果需要独立实验评价。

本证明的实现对应为 [有界质量函数](../../environment/types.py) 中的 bounded_quality_score 和 [全局观测编码](../../environment/observation_schema.py)。证明针对确定性目标值及标量问题的全局最优解，不将其延伸为 PPO 全局收敛、随机策略期望目标排序或偏好网格完整性的结论。

**6．三次取优中的有限候选最优性**

对同一实例、固定偏好、同一原生尺度的三个完整候选，若至少一个成功，当前协议在成功候选中取 Q 最小者。当所有偏好严格为正且 rho>0 时，命题3保证该交付不被同一成功候选集中的另一份方案支配；零权重端点仍受命题5的边界约束。这里的最小值仅遍历实际采样到的候选，并非全部可行调度，也不证明 PPO 收敛或完整 Pareto 前沿覆盖。

checkpoint 根据完成率和逐偏好成功交付的平均 Q 选择。平均 Q 与平均目标的 Q、不同成功子集上的平均 Q 均需区别，见 [三次取优与选模证明](SELECTION.md)。
